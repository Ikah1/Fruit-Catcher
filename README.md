# Fruit-Catcher
Simple C++/SFML Game where you catch falling fruit in a basket for points and try to avoid falling obstacles as they will take points away.
This is a massive work in progress and the code is not great as i'm just a beginner trying to learn!

Unless you only plan to use/look at the code, you will need a compiler and SFML installed on your system as i don't know how to link them properly.
